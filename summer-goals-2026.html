Setting Horizons: Summer 2026 Goals

Summer is the best time to build without constraints. Freed from the schedule of SJU coursework, my goal for this summer is to double down on system building and interactive storytelling. I've laid out three core areas I want to focus on before the fall semester begins.

1. Deep Dive into Systems Architecture & ECS

Building the *Micro-ECS in Python* prototype opened my eyes to data-oriented design. This summer, I want to take those learnings and apply them to a larger codebase. Specifically, I plan to:

  • Extend my ECS engine to handle spatial partitioning and complex component queries efficiently.
  • Refactor backend APIs to optimize database queries, drawing on what I did with the *Leaderboard & Stats API*.
  • Write a technical post breaking down the tradeoffs between Object-Oriented game loops and Data-Oriented designs.

2. Ship a Playable Narrative Prototype

Code is the engine, but story is the goal. I want to build a small, text-based or minimal-graphic procedural mystery game. It will combine my interests in narrative system design and terminal-based interfaces. I want to explore:

  • Procedurally generated dialog trees using state machines.
  • A lightweight narrative state-tracking system that ensures player choices have clear, cascading consequences.
  • Publishing the game directly to the browser (using standard Web components or Canvas API).

3. Leveling Up Backend & Infrastructure Skills

I want to make my web applications more resilient and scalable. This means moving beyond local setups to clean cloud-native development. My goals are:

  • Integrating Redis caches for hot paths in my backend APIs to reduce response times.
  • Setting up automated CI/CD pipelines (via GitHub Actions) to run tests and linters on push.
  • Building out a small mock messaging system using WebSockets to support real-time data sync.

Looking Ahead

Setting goals is easy; executing is where it counts. I'll be committing regularly to GitHub and updating my progress in the *Labs* section of my site. If you have recommendations, want to collaborate on a prototype, or just want to chat system architecture—reach out!
